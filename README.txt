  Gerador de Sensibilidade Android
  Versão 1.0
============================================

DESCRICAo
  Site premium para gerar sensibilidades aleatorias
  para Free Fire (Atual e 2022) no Android.
  Visual de aplicativo com design gamer premium.

TECNOLOGIAS
  - HTML5
  - CSS3
  - JavaScript Vanilla (sem frameworks)

COMO USAR
  1. Abra o arquivo index.html no navegador
  2. Escolha a aba: Free Fire Atual ou Free Fire 2022
  3. Selecione a versao: Free Fire ou Free Fire MAX
  4. Clique em "GERAR SENSIBILIDADE"
  5. Os valores serao gerados automaticamente
  6. Clique em "GERAR NOVAMENTE" para novos valores
